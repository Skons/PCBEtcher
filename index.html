PCB Etcher

What does this tool do?

You load an SVG of a PCB design. From that, the tool builds a 3D model: either the PCB itself (with recessed traces/pads as an etching preview), or an etch template (a mold used to etch/engrave the PCB).

SVG

Load the source file here. The colors in the SVG determine what counts as traces, pads and holes (see the Colors section).

Colors

Outer edge: color of the outer outline of the PCB. Traces / circles: color of the traces and pads. Hole colors: link colors to holes with a diameter, for through-holes in the PCB.

Model — PCB

Generates the PCB itself, with adjustable total thickness and depth/width of traces and pads. Useful as a 3D reference model.

Model — Etcher

Generates a template shape to hold the PCB in and etch it. It consists of an outer wall on the outline, a base layer (infill), and raised borders around traces/pads/holes that act as an etch mask.

Base infill – Honeycomb: the base layer is filled with a lightweight honeycomb pattern (less material, prints faster). Always stays within the outer edge.

Base infill – Solid: the base layer is one solid slab, with no pattern. Sturdier, but uses more material.

Etcher thickness: thickness of the base layer. Etcher tolerance: how much extra room the recesses for traces/pads/holes get compared to the PCB design, so the PCB fits in easily. Cell size / wall width: size and wall thickness of the honeycomb cells (Honeycomb only).

Mesh

Arc segment resolution: how many segments round shapes (circles/holes) get — higher is smoother but heavier to render. Refresh 3D rebuilds the model after changes. Download PCB/etcher STL exports the current model as a 3D-printable file.
